A note at the very top of the README, above Buzz's centered title block, says this is a personal fork of Buzz (linked to https://github.com/block/buzz) that updates itself with autofork (linked to https://autofork.com). It says the fork carries a few small changes, each written as a future upstream PR and described in plain words in the `.autofork/` folder (linked), and that each sync builds the macOS app into the `buzz-desktop-fork-latest` release (linked to https://github.com/AVGVSTVS96/buzz/releases/tag/buzz-desktop-fork-latest), which installs of the fork update from. The note comes first and ends by saying everything below is upstream's README, unchanged, and nothing below it differs from upstream.

It stays as long as the fork does. To drop it, delete the note from the README and this folder, in the same commit.
